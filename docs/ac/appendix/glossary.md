# 附录 C · 术语与译名对照

> 全书统一使用的人名、组织、地名和术语译法。前半部分是写作时锁定的统一译名表；后半部分收录在两章以上反复出现的其他词条。只在一章出现的配角、任务名和地名，见各章末尾的「译名补充」表。

## 本章要点

- 译名优先采用育碧官方简体中文版和中文玩家社区最通行的说法；没有通行译法的，按音译或意译自拟，并在正文首次出现时附英文。
- 「Animus」「Animus Hub」「Helix」等系列专有的装置和平台名保留英文不译。
- 同一人物有多个名字时（例如拉顿哈给顿与康纳、阿雅与阿穆奈特），正文首次出现会说明，之后用最常见的称呼。
- 「主要章节」一栏按该名字在各章出现的次数自动挑选，最多列三章，便于回查。
- 作品名一律加书名号；PSP 外传《血统》（Bloodlines）与真人短片《世系》（Lineage）是两部不同的作品。

# 附录 C · 术语与译名对照

> 全书统一使用的人名、组织、地名和术语译法。这里只收跨章节反复出现的核心词条；只在一章出现的配角、地名和章节名，见各章末尾的「译名补充」表。

## 本章要点

- 译名优先采用卡普空官方简体中文版的译法；官方没有中文版或各版本说法不一的，用中文玩家社区最通行的说法，并在首次出现时附英文。
- 系列在日本叫《Biohazard》（バイオハザード），在欧美叫《Resident Evil》。本书统一称《生化危机》，作品名按中文通行叫法，例如《生化危机：村庄》《生化危机：安魂曲》。
- 「伞公司」与「安布雷拉」指同一家公司（Umbrella Corporation），本书正文统一用「伞公司」。
- 病毒名中的字母保留原样：T 病毒、G 病毒、C 病毒；寄生虫与真菌类写作「普拉卡（Las Plagas）」「菌根（Megamycete）」。

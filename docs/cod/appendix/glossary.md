# 附录 C · 术语与译名对照

> 全书统一使用的人名、组织、地名和术语译法。这里只收跨章节反复出现的核心词条；任务名和只在一章出现的配角，见各章末尾的「译名补充」表。

## 本章要点

- 译名优先采用中文玩家社区最通行的说法；没有通行译法的，按音译或意译自拟，并在首次出现时附英文。
- 同一个英文名在不同宇宙指代不同人物时（例如两个加兹、两个扎卡耶夫），译名相同，正文会注明是哪个宇宙的版本。
- 僵尸地图名第一次出现时都附英文原名；《黑色行动7》的 Kowakujō 保留原名。

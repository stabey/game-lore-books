# 系列总览：几个宇宙，怎么连起来

> 一句话概括：《使命召唤》的战役大致分成六块：早期二战作品、现代战争原三部曲、「黑色行动 × 重启现代战争」共享宇宙、《先锋》、《二战》，以及三个各自独立的未来/架空宇宙。僵尸模式另有自己的三条故事线。

## 本章要点

- 系列没有一条贯穿始终的主线。早期二战作品、原三部曲、《幽灵》《高级战争》《无限战争》，都是各自封闭的故事。
- 真正连成一片的是**黑色行动宇宙**：《战争世界》的苏军线是它的起点。2020 年起，官方又把 **2019 年重启的现代战争**并入同一个宇宙。
- 「同一个宇宙」不等于「同一个故事」。黑色行动和重启现代战争的战役几乎没有直接交集，所以本书仍把它们分成两卷来讲。
- 重启宇宙里的普莱斯、肥皂、幽灵，与 2007–2011 年原三部曲里的同名人物**不是同一个人**，经历也不一样。
- 僵尸模式的「以太」故事线在《黑色行动4》完结；从《黑色行动：冷战》开始的「暗以太」发生在黑色行动宇宙里，到 2026 年 8 月也已收尾。

## 逐块说明

### 早期二战作品（2003–2006）

《使命召唤》《使命召唤2》《使命召唤3》以及资料片《联合进攻》、主机外传《大红一师》，都是「以真实战役为舞台、虚构士兵为主角」的群像故事。每作开头都分成美、英、苏（《使命召唤3》还有加拿大和波兰）几条战线，人物之间很少有跨作品的延续。

唯一常被拿出来讨论的是**普莱斯上尉**：英军线的普莱斯在初代和《使命召唤2》里都出现了，而《现代战争》系列的主角也叫约翰·普莱斯。两者是什么关系，开发者从未正式确认，[卷一](../ww2/cod1.md)和[人物志](../people/mw.md)会专门讲。

### 现代战争原三部曲（2007–2011）

《现代战争》《现代战争2》《现代战争3》是一个首尾完整的故事：从 2011 年的核爆讲到 2017 年马卡洛夫之死。它自成一个宇宙，后来没有续作，2016 年和 2020 年的两部重制版也只是把原作重做一遍。

### 黑色行动 × 重启现代战争：共享宇宙

这是目前系列里规模最大、仍在延续的一块。它的两条主干是：

- **黑色行动线**：始于《战争世界》的苏军线（1945 年），经《黑色行动》（1960 年代）、《黑色行动：冷战》（1981）、《黑色行动2》（1980 年代与 2025 年）、《黑色行动6》（1991）、《黑色行动7》（2035）。《黑色行动3》（2065）和《黑色行动4》（2043）是同一时间线上的远未来，但与梅森家族的故事只有零星联系，本书放在卷三末尾作为支线。
- **重启现代战争线**：2019 年的《现代战争》重新讲述普莱斯与 141 特遣队的故事，经《现代战争II》《现代战争III》到 2026 年的《现代战争4》。

两条线是怎么被认定为同一个宇宙的？关键在 2020 年。《黑色行动：冷战》的任务「非常手段（Desperate Measures）」里，克格勃第一总局的伊姆兰·扎卡耶夫亲自出场，在电梯里盘问乔装潜入的阿德勒和贝尔；同年的僵尸地图 Firebase Z 结尾过场也把两边串了起来；再加上把各作角色放在一起的《战区》（Warzone），动视借此确认重启的现代战争与黑色行动 1/2/冷战处于同一时间线。

::: warning 存疑
官方的「共享宇宙」更多是背景层面的确认，并没有推出一部让梅森和普莱斯并肩作战的战役。《战区》里各作角色同场出现，一般不被当成剧情正史。至于原三部曲是否也属于这个宇宙，官方没有这样说过，主流看法是它独立存在。
:::

### 《先锋》（2021）

《先锋》讲二战末期一支「特种部队雏形」小队的故事，战役本身是封闭的二战叙事。它与共享宇宙的联系主要在战役之外：上市前的《战区》宣传片里，冷战时期的阿德勒在维尔丹斯克的德军地堡里见到了《先锋》的人物；它的僵尸模式由 Treyarch 制作，直接延续了暗以太故事线。

::: warning 存疑
没有官方说法明确《先锋》的战役与黑色行动、重启现代战争处在同一时间线。本书把它归为「与共享宇宙松散相连」：它的僵尸与《战区》内容是相通的，战役不受影响。
:::

### 《二战》（2017）

Sledgehammer 的《二战》是一部独立的二战故事，以美军第一步兵师的一个班为主角，从诺曼底一路打到莱茵河。它和早期二战作品、和黑色行动都没有剧情关系。它的纳粹僵尸模式也是一条自成一体的故事线，放在[外传僵尸](../zombies/others.md)里讲。

### 三个独立的未来宇宙

- **《幽灵》（2013）**：南美联邦用天基武器摧毁美国西南部之后的战争，结尾留下悬念，但续作始终没有出现。
- **《高级战争》（2014）**：私营军事公司阿特拉斯与外骨骼的时代。
- **《无限战争》（2016）**：人类殖民太阳系后的星际战争。

三者互不相通，也不属于上面任何一个宇宙。《幽灵》里曾经藏有《高级战争》的预告彩蛋，但那只是开发团队之间的玩笑，不构成剧情连接。

### 僵尸：另一套宇宙观

僵尸模式从《战争世界》的隐藏模式起步，后来长成了系列里最复杂的故事。它有三条官方故事线：

- **以太（Aether）**：《战争世界》到《黑色行动4》，围绕 935 小组、115 元素和终末组/原初组展开，涉及多元宇宙与时间循环，在《黑色行动4》的 Tag der Toten 完结。
- **混沌（Chaos）**：《黑色行动4》新开的一条线，只有四张地图，之后没有延续。
- **暗以太（Dark Aether）**：从《黑色行动：冷战》开始，经《先锋》、《现代战争III》僵尸、《黑色行动6》到《黑色行动7》，发生在黑色行动宇宙里，2026 年 8 月的 Rex Infernus 是它的终章。

此外，《幽灵》《高级战争》《无限战争》《二战》各有自己的合作/僵尸模式，彼此独立。详细的关系和推荐阅读顺序见[僵尸宇宙总览](../zombies/overview.md)。

**第一次读：按目录顺序。** 一卷一条线，每卷都能独立成篇。

**只想看最有名的故事：**

1. [现代战争](../mw/cod4.md) → [现代战争2](../mw/mw2.md) → [现代战争3](../mw/mw3.md)
2. [战争世界](../ww2/waw.md) → [黑色行动](../bo/bo1.md) → [黑色行动2](../bo/bo2.md)
3. [人物志 · 现代战争](../people/mw.md)：看原版与重启版的普莱斯、肥皂、幽灵有什么不同

**按发售顺序重温：** 照上面那张表从上往下读，体验每一年的玩家拿到新作时的感受。

**只看僵尸：** 从[僵尸宇宙总览](../zombies/overview.md)开始，卷六可以完全独立阅读。
